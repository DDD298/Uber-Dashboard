14. CHỨC NĂNG ĐÁNH GIÁ
14. 1. CƠ SỞ DỮ LIỆU
- Table:
TABLE ratings (
  id SERIAL PRIMARY KEY,
  ride_id INTEGER NOT NULL REFERENCES rides(ride_id),
  user_id VARCHAR(255) NOT NULL REFERENCES users(clerk_id),
  driver_id INTEGER NOT NULL REFERENCES drivers(id),
  stars INTEGER NOT NULL CHECK (stars >= 1 AND stars <= 5),
  comment TEXT,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
- Quan hệ:
+ ride_id -> rides.ride_id (1-1): Mỗi chuyến đi chỉ có 1 đánh giá
+ user_id -> users.clerk_id (N-1): Một user có thể có nhiều đánh giá
+ driver_id -> drivers.id (N-1): Một tài xế có thể nhận nhiều đánh giá

14.3. API ENDPOINTS
14.3.1. POST /api/rating/create
File: app/(api)/rating/create+api.ts
- Mục đích: Tạo đánh giá mới
- Vị trí: app/(api)/rating/create+api.ts (dòng 7-85)
- Method: POST
- Authentication: Required (Clerk user_id)
Request Body:
{
  "ride_id": 123,
  "user_id": "user_2abc123",
  "driver_id": 456,
  "stars": 5,
  "comment": "Tài xế lái xe rất tốt!" // Optional
}
Response Success (201):
{
  "success": true,
  "data": {
    "id": 789,
    "ride_id": 123,
    "user_id": "user_2abc123",
    "driver_id": 456,
    "stars": 5,
    "comment": "Tài xế lái xe rất tốt!",
    "created_at": "2026-01-09T09:43:00.000Z"
  },
  "message": "Đánh giá thành công"
}
Response Error:
- 400: Thiếu thông tin, số sao không hợp lệ, chuyến chưa hoàn thành
- 404: Không tìm thấy chuyến đi
- 409: Chuyến đi đã được đánh giá
- 500: Lỗi server

14.4. LUỒNG HOẠT ĐỘNG CHI TIẾT (USER FLOW)
Bước 1: Tại màn hình Lịch sử chuyến đi (Rides Screen)
- Tìm chuyến đi có trạng thái đã hoàn thành.
- Nhấn vào nút Đánh giá tài xế (màu vàng) bên dưới thông tin chuyến đi.

Bước 2: Modal đánh giá xuất hiện (Rating Modal)
- Người dùng nhấn vào các icon ngôi sao (từ 1 đến 5) để chọn mức độ hài lòng.
- Mặc định khởi tạo là 5 sao.
Bước 3: Nhập nhận xét (Tùy chọn)
- Nhấn vào ô Nhập nhận xét bên dưới phần chọn sao.
- Gõ nội dung đánh giá (tối đa 500 ký tự).
Bước 4: Gửi đánh giá
- Nhấn vào nút Gửi đánh giá ở cuối modal.
- Chờ hệ thống xử lý (hiển thị loading).
Bước 5: Xác nhận thành công
- Một thông báo Đánh giá thành công xuất hiện.
- Nhấn nút OK để đóng modal.
Bước 6: Xem kết quả
- Màn hình Lịch sử chuyến đi tự động cập nhật.
- Nút bấm Đánh giá tài xế biến mất, thay vào đó là thông tin số sao và nhận xét đã gửi.
